# HocTuThien Frontend

Nền tảng giao diện người dùng (Client-side) dành cho Mentee và Mentor trong dự án HocTuThien.

## 🛠 Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS / Vanilla CSS

## 🎯 Key Tasks
- Phát triển Landing Page chuyên nghiệp.
- Xây dựng hệ thống Booking và Dashboard cho Mentor/Mentee.
- Tích hợp thanh toán và đối soát quyên góp minh bạch.
