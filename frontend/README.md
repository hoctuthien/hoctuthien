# 🤝 MentorConnect - Frontend

Dự án giao diện cho nền tảng **Học Từ Thiện**.

---

## 🛠 Công nghệ cốt lõi
- **Framework**: Next.js 15+ (App Router)
- **Library**: React 19, TypeScript
- **Styling**: Tailwind CSS 4, Vanilla CSS
- **Tools**: Storybook, Lucide Icons

---

## 🧩 Thành phần (Components)
Các UI components được xây dựng sẵn trong `src/shared/components`:
- Pagination, Dropdown, Steps, Sidebar, Button, Breadcrumb...

---

## 🚀 Hướng dẫn chạy
- **Phát triển**: `npm run dev` (Cổng 3000)
- **Storybook**: `npm run storybook` (Cổng 6006)

---

## 📜 Quy ước Commit
Định dạng: `<type>(<scope>): <mô tả ngắn>`
- **Scopes**: `booking, charity, core, shared, auth, config`...
- **Ví dụ**: `feat(shared): add steps component`
