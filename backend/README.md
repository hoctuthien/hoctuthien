# HocTuThien Backend

Core API và Logic xử lý cho nền tảng HocTuThien.

## 🛠 Tech Stack
- **Framework**: NestJS (Node.js)
- **Language**: TypeScript
- **ORM**: TypeORM
- **Database**: PostgreSQL
- **Caching**: Redis

## 🎯 Key Tasks
- Quản lý Hồ sơ Mentor và Mentee.
- Xử lý Đặt lịch học & Logic Phiên Mentoring.
- Tự động hóa Đối soát Quyên góp Charity.
- Quản lý Chiến dịch thiện nguyện & Admin Dashboard.
